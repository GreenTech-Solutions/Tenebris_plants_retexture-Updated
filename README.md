# Tenebris_plants_retexture-Updated

> Fork of [Tenebris plants retexture](https://mods.factorio.com/mod/Tenebris_plants_retexture) by mafisto, updated for
> Factorio 2.1 and published as `Tenebris_plants_retexture-Updated`. All credit for the mod and its textures goes to
> mafisto. The original has no public repository: `master` up to the tag `v1.0.0` is release 1.0.0 from the mod portal
> as it is.

The fork changes what 2.1 needs; the list is in [changelog.txt](changelog.txt).

## Switching from Tenebris plants retexture

Remove the original and install this mod: the two do not load together. Only the look of the plants changes.
